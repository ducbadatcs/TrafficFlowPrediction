# READ THIS (for Kiet)

How to setup:

- clone this repo. Use Python 3.13 (or whatever, 3.13 is preferred)
- create a venv: `python -m venv .`
- Activate the venv: `./Scripts/Activate.ps1`
- Install packages: `pip install -r requirements.txt`

Commentary:
